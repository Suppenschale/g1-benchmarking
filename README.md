# Benchmarking Setup

This repository runs benchmarks on the following machines:

| Name         | Hardware                            | Location |
|--------------|-------------------------------------|----------|
| kent-yuria   | Intel Xeon CPU E5-2620 v3 @ 2.40GHz | Kent     |
| kent-yuria2  | Intel Xeon Gold 6209U CPU @ 2.10GHz | Kent     |
| kent-yuria3  | Intel Xeon Gold 6209U CPU @ 2.10GHz | Kent     |
| kent-yuria4  | 13th Gen Intel Core i9-13900K       | Kent     |
| kent-zullie1 | Apple M2 ARM                        | Kent     |

yuria, yuria2, and yuria3 give the most stable results.
The other machines have hardware that makes benchmarking more difficult.
